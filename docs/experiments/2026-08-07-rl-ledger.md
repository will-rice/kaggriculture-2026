BUG CAUGHT BEFORE MEASUREMENT (Fable, verified by me at the code level):
`rollout.py:753-754` stored `potential(terminal)` un-zeroed in the shaping
agent's live uncommitted work. Grzes (AAMAS 2017) Eq. 3: the shaped return
differs from the true return by `g^N * Phi(s_N) - Phi(s_0)`; the first term is
action-dependent and "can modify the policy"; the potential "has to be set to
zero" at a trajectory's stopping state. Every trajectory stops at turn 719 in a
state whose held produce the agent chose. At gamma=0.999, holding produce from
turn 619 to the horizon returns 0.905 of its shaped value, so in a market both
farms push below base, REFUSING TO SELL IS SHAPED-OPTIMAL. "Shed fills, bank
flat" was built into the reward. Fix dispatched with a behavioural guard (an
episode ending holding produce must not out-score one that sold it) and
pre/post-fix numbers reported separately.
This is the THIRD instance of the project's recurring failure -- a shaped term
maximised without banking -- and the first caught before it was measured.
